What Is Markdown?

Markdown is a lightweight markup language that lets you format plain text using simple characters. Instead of opening complex formatting menus, you can type # Heading, **bold**, *italic*, - list item, or fenced code blocks. A Markdown parser converts that readable source into HTML for display.

Because Markdown files are plain text, they are easy to edit, review, version, and store with software projects. Markdown is especially common in GitHub repositories, README files, open-source documentation, technical blogs, changelogs, project notes, and developer knowledge bases.

Markdown Syntax Cheat Sheet

You can use the following common Markdown patterns in this online Markdown previewer:

  • Heading: # Heading
  • Subheading: ## Subheading
  • Bold: **Bold text**
  • Italic: *Italic text*
  • Bullet list: - Item
  • Numbered list: 1. Item
  • Link: [Text](https://example.com)
  • Image: ![Alt text](image-url)
  • Inline code: `code`
  • Code block: three backticks before and after the code
  • Blockquote: > Quote
  • Horizontal rule: ---
